# f1-commercial-dashboard sponsor analysis
“Exploring F1 team sponsorship patterns through a custom dataset and commercial insights dashboard.”

## Overview
This project analyses just a small part of the commercial landscape of Formula 1 by exploring the distribution of sponsorships across categories, regions, value levels and teams.
The goal of this project is to provide a clear, data-driven view of how F1 teams attract commercial partners and what market segments exist across the sport.

This project is a part of my portfolio for data roles in motorsports, including commercial, digital intelligence and data analysis roles.

## Dataset

The dataset contains sponsor information such as: Sponsor name, Category, Region, Value Level, Visibility and Team.
Source: Manually compiled dataset for analysis and dashboard development using team websites and official imagery.

## Methods

This project used: Python - for processing the data, Pandas - for cleaning and grouping data, Matplotlib - for creating charts, groupby() - to section off category, region and value level, and Jupyter Notebook - for analysing data and documenting the project.

The project focuses on simple easy to read data so there is room to grow and expand the project later.

## Results

Category Insights - The distribution shows a wide array of sponsor categories but clearly certain sectors like technology, automotive and finance appear more often. This reflects the areas where brands see the strongest links to F1's global audience and product usage as all teams must have a top-level technology to analyse all the data, its a motorsport so it connects well with automotive companies and all F1 teams must abide by the cost cap so they all have high quality finance teams to ensure they don't go over budget.

Region Insights - The graph shows that the majority of sponsors have their headquarters in Europe. This aligns with the fact that majority of the F1 teams are based in Europe and Europe hosts a lot of races each season. However, there still is notable sponsorship representation from North America and Asia, this shows F1's expanding global commercial reach and is boosted by the fact that more drivers are coming from outside Europe and the addition of Cadillac the first American F1 team.

Value Level Insights - The most prominent sponsorship tiers are high and medium. This shows that to be an F1 sponsor you need to go all in and be of a very high standard. Of course there are some low tier sponsors but those companies wouldn't get as much visibility.
